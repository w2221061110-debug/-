# Wudu Duck Deli

Open `index.html` in a modern browser. No build or dependencies are required.

Recreated from the supplied screenshots: warm cream canvas, pink dish controls, plum cart, gold actions, pastel emoji artwork, category sidebar and fixed navigation. Responsive layouts cover mobile and desktop.

## Features

- Open a dish title for **Bite Details**. The slider chooses Mild, Medium or Hot. Each cart line retains its spice level.
- **Save request** in Your Selection stores the order locally. **Repeat last order** on the menu or Profile restores quantities and spice levels, replacing the current selection.
- **Clear selection** empties the cart and updates the badge and total.
- Quantity controls, favorites, collection/delivery selection and request notes work locally.

Cart, favorites and the last request use browser localStorage. There is no server, payment integration or request transmission. Contact details were not provided.

## Reconstruction limits

The original source was not found in the two requested GitHub repositories. Past Codex chat history was not available through this session's tools. Six visible dishes and their prices/descriptions were transcribed; the other ten dishes are provisional entries to complete the pictured 16-item menu. The hero uses a substitute Unsplash food photo that requires internet access; the original photo, font and platform emoji artwork were unavailable. Screenshot copy referring to Sichuan-style bites was preserved. The page is a functional visual reconstruction, not a pixel-exact copy.

## Validation

JavaScript DOM checks cover spice selection, quantities, totals, request saving/restoration, clearing and persisted state, delivery validation, favorites and HTML escaping. Browser visual comparison was not available in the execution environment.
